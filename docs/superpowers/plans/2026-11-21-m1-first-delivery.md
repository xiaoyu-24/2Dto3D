# M1 首件交付实施提案

基线 `c815621`，接续工作台任务 #2 已冻结的 `M12A04-03-301-M16/A0/M1.3`。本次实现一条可复跑的首件作业，交付离线单文件 HTML、STEP 和验收报告。在独立 Compose 项目验证入库和发布。

**领域契约**　原图、建模依据、独立清单各以字节 SHA-256 校验。`G1` 几何由零件 BREP、部件清单、变换及发布前冻结的清单指纹追溯。由带键配合端指向焊线端为 +Z。本体 A×1、B×4、C×1、E×1，独立螺母 D×1。D 的安装变换未定，STEP 和 HTML 中的位移只用于分件展示。面板开孔单列参考，灌封记录在说明中。试建项保留依据与用途。仓库未提供 `CONTEXT.md` 和 `docs/engineering-ai-guardrails.md`，采用 `AGENTS.md`、实施方案和已冻结的 M1.3 输入。

**影响范围与实施**

1. `m1/` 消费两份冻结输入，使用 M0 Harness 让模型选择固定范围的本地 CAD 作业。用锁定的 Linux FreeCAD 镜像冻结 BREP、零件和变换，重开冻结文件并从同一清单导出两项成品。
2. 另起隔离进程导入待交付 STEP 字节，依清单测量几何和端面。端面对调、26.70 mm、26.90 mm 的三份四针负例也实际导出并回读。用离线 Edge 从本地文件检查可见网格、旋转、缩放、视角和显隐，汇总报告并绑定成品哈希。
3. 应用复用 `file_bytes`、任务和权限，在一个事务发布报告及两项成品。任务详情给出同版本的三条下载。临时目录清理后，新 Edge 客户端登录下载，逐项比较实收字节数、SHA-256 和 MySQL。复跑现有后端测试并覆盖发布拒绝与下载权限。

**风险与验收边界**　图纸未定的牙型公差、端子细节和内腔过渡保留为模型假设。螺距和名义规格按 STEP 上的实际螺旋几何量测。验收覆盖所列尺寸、几何一致性与交互，旋合、密封、电气和生产认证属于另行验证。任何指纹错配、几何回读失败、离线交互失败或负例漏放均停止发布。已确认范围内无待确认事项。
